# 🚀 Al Rihla Landing Page

## 🔗 Demo

- **Live Site:** [Al Rihla Landing Page](https://khayre-ddine.github.io/Landing_Page)
- **Source Code:** [GitHub Repository](https://github.com/KHAYRE-DDINE/Landing_Page)

---

A modern, animated, and responsive landing page for the **Al Rihla** educational platform, built with React, Tailwind CSS, and Framer Motion. This project showcases a beautiful user experience with dark mode, multi-language support (English & Arabic), and engaging animations.

---

## ✨ Overview

**Al Rihla** is designed to empower students, parents, teachers, and schools with a seamless educational journey. The landing page introduces the platform, highlights its unique features, and invites users to join the beta or contact sales.

---

## 🌟 Features

- 🎨 **Stunning Design & Animations** — Smooth transitions and interactive elements powered by Framer Motion.
- 🌗 **Dark Mode** — Instantly switch between light and dark themes for comfortable viewing.
- 🌍 **Multi-language Support** — English and Arabic landing pages for broader accessibility.
- 📱 **Fully Responsive** — Optimized for all devices and screen sizes.
- 📨 **Beta Sign-up & Contact Forms** — Easy access for early adopters and inquiries.
- 👨‍🎓 **Audience Sections** — Tailored content for students, parents, teachers, and schools.
- 🛡️ **Secure & Fast** — Built with best practices for performance and data safety.

---

## 🛠️ Tech Stack

- **React** — UI library for building interactive interfaces
- **Tailwind CSS** — Utility-first CSS framework for rapid styling
- **Framer Motion** — Advanced animations and transitions
- **React Router** — Routing and navigation
- **GitHub Pages** — Deployment
